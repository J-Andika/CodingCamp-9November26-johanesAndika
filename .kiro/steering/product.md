# Expense & Budget Visualizer — Product Overview

## What It Is
Mobile-friendly web app for tracking daily spending. No backend, no accounts — all data stays in the user's browser.

## Target Users
Individuals who want a simple, fast way to log expenses on mobile. No spreadsheets, no complex finance apps.

## Core MVP Features
1. **Add Transaction** — Form with Item Name, Amount, Category (Food, Transport, Fun). All fields required and validated.
2. **Transaction List** — Scrollable history showing name, amount, category with delete per item.
3. **Total Balance** — Auto-updates on add/delete, displayed prominently at top.
4. **Pie Chart** — Spending distribution by category, updates when data changes (Chart.js).

## Optional Challenges
- **Sort Transactions** — Sort by amount or category.
- **Spending Limit Highlight** — Set a budget limit; total turns red when exceeded.
- **Dark/Light Mode Toggle** — Theme preference persists across sessions.
